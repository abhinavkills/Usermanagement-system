# Python User Management System

A simple User Management System built in Python to practise user authentication, JSON file handling, and modular programming.

## Features

* User registration
* User login
* Stores user data in a JSON file
* Basic input validation

## How It Works

User data is stored locally in a JSON file using Python's built-in `json` module. New users are added during registration, and login credentials are checked against the saved data.

## Limitations

This project is built for learning and isn't designed for large amounts of data. It also stores passwords in plain text, so it should not be used in a real application.

## Future Improvements

* Optimise the code
* Hash passwords
* Replace JSON with a database
* Add more user management features

This project was a great way to get hands-on experience with Python file handling and authentication.
